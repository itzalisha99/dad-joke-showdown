One dad joke (89 characters), written to be told out loud at the dinner table:

> I tried to start a band called The Leftovers. We never got a gig — nobody wanted seconds.

`main.py` (Python 3, stdlib only, no network, deterministic) writes that
joke to `/output/entry.txt`, with a built-in check that it stays within the
bounty's 1–200 character, single-line gate.
